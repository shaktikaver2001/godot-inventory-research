# Forge & Field

Godot inventory and crafting prototype for Horse_Plinko. Built with GDScript and AI assistance.

## Run

Import `project.godot` in Godot 4.7 and press **F5**.

## Features

- Collect wood and iron.
- Craft a sword with 3 wood and 2 iron.
- Equip the sword to increase attack from 5 to 10.
- Filter inventory by materials or weapons.
- Take damage and heal with a three-second cooldown.
- Reset the demo.

## Files

- `main.gd`: interface and button actions.
- `state.gd`: inventory, crafting, equipment, and health rules.
- `test_state.gd`: game-rule tests.
